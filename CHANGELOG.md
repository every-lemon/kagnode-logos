# Changelog

## Declared Core binding preview

Clarify that the static gallery is rebuilt with Core at publication time and does not create server bindings or run an update daemon. Existing artwork, viewer paths and licenses are retained.

## Shared loading spinner preview

Use KagNode Core 1.0.5 for the shared split-orbit loading mark, with reduced-motion support and existing status/recovery controls retained. This changes web presentation without resetting data or provisioning native services.

## Core integration preview

Shared local UI components, manual animated navigation, natural scrolling rails and icon account menus. Added separate appearance-only account connections and signed UI patch controls. Existing storage, native services and prior release records are retained.

## Public library cleanup · November 7, 2026

Removed retired internal-use branding from the current public artwork library. Historical tags and published release assets retain their existing provenance.

## Gallery fixes · November 7, 2026

- Replaced repeated per-file cards with grouped designs and original-format download choices.
- Added matching artwork previews for EPS/PDF/ICO/ICNS and readable terminal artwork, verified image decoding, automatic contrast and an embedded transparent favicon.
- Reworked responsive navigation, filters and the saved HTML viewer; hidden menus cannot leave floating scrollbars.

## Packaging preview

Added shared release formats, repository documentation and validation.
