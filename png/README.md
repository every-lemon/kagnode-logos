# KagNode PNGs

The symbol-only variants are directly in this folder as **`mark-{style}-{color}-{size}.png`**. Every symbol PNG has a transparent background and contains only the geometric logo, without words or a period.

- Styles: `solid`, `outline`, `two-tone`.
- Colors: `black`, `white`, `charcoal`, `gray`, `light-gray`, `slate`, `blue`, `light-blue`.
- Square sizes: `16`, `24`, `32`, `48`, `64`, `128`, `256`, `512`, `1024`, `2048` px.

Examples: [black](mark-solid-black-1024.png), [white](mark-solid-white-1024.png), [gray](mark-solid-gray-1024.png), [light gray](mark-solid-light-gray-1024.png), [blue outline](mark-outline-blue-1024.png), [gray two-tone](mark-two-tone-gray-1024.png).

The existing wordmarks, product layouts and logo sheet are also retained here under their original filenames.
